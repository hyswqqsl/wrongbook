# AI 错题本（数学）

照片 → AI 排版机转录 → 人审 → 错题知识库 → 刷题练习 / 导出 PDF 打印。
**数据全部存本机，支持多用户隔离**；教材知识树自动归类知识点；专题模块（主动备考）
与错题本（被动纠错）双体系；激活码授权（ECS 公网验证，数据不出户）。
当前版本 **V1.4.0**，回归测试 **208 项全绿**。
